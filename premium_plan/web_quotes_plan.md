# 🌐 خطة عروض الأسعار التفاعلية عبر الويب (Interactive Web-Quotes Plan)

توضح هذه الخطة كيفية تطوير وبناء نظام عروض الأسعار التفاعلية عبر الويب، ليتمكن الزبائن من فتح عروض أسعارهم من المتصفح مباشرة، وتعديل خياراتهم، والموافقة على الطلب بنقرة واحدة.

---

## 🏗️ التصميم المعماري للويب (Architecture Design)

بما أن تطبيق **Stream Pay** تطبيق للهواتف المحمولة، لتوفير صفحة ويب يراها العميل، سنعتمد على بنية هجينة وخفيفة للغاية:

```text
┌─────────────────┐             ┌───────────────────┐             ┌───────────────────┐
│  تطبيق البائع   │ ──────────> │   Supabase DB     │ <────────── │   صفحة ويب الزبون  │
│  (Flutter Mobile)│             │ (بيانات عرض السعر)│             │  (HTML/CSS/JS)    │
└─────────────────┘             └───────────────────┘             └───────────────────┘
```

1. **توليد الرابط (Link Generation):**
   * عند قيام البائع بحفظ عرض سعر، يتم توليد رمز تعريف فريد (Token) طويل ومشفر لعرض السعر هذا.
   * يقوم التطبيق بإنشاء رابط ويب مثل: `https://[shop-subdomain].supabase.co/storage/v1/object/public/web-quotes/quote.html?id=[quote_token]`.
2. **استضافة صفحة عرض السعر (Web Page Hosting):**
   * سنقوم برفع صفحة ويب واحدة فائقة الجمال ومستجيبة (Responsive Single Page) مكتوبة بـ Vanilla HTML & CSS & JavaScript إلى **Supabase Storage bucket** عام أو استضافة مجانية على Vercel/Netlify.
   * تقرأ هذه الصفحة معرّف عرض السعر من رابط الـ URL، وتتصل بـ Supabase API لجلب بيانات المنتجات والأسعار الخاصة بالزبون وعرضها بشكل تفاعلي ومنسق.
3. **التفاعل المباشر والتحديث (Real-time Interaction):**
   * يمكن للزبون زيادة/نقص كميات المواد.
   * يمكن للزبون تفعيل أو إلغاء تفعيل الخامات المساعدة (مثل لاصق السيليكون، الفوم، شريط الليد).
   * يتم إعادة حساب السعر الإجمالي في الـ DOM مباشرة.
   * عند نقر الزبون على "تأكيد الطلب وشراء"، يتم تحديث حالة الفاتورة في Supabase إلى "مؤكدة من العميل" مع تحديث الكميات الجديدة المختارة، مما ينعكس فوراً في تطبيق البائع كإشعار.

## 💾 تصميم البيانات والتعديلات (Data Modifications)

تعديل جدول `quotes` (أو إنشاء جدول ملحق `premium_web_quotes` لحماية الفصل مستقبلاً):

```sql
CREATE TABLE IF NOT EXISTS public.premium_web_quotes (
    id uuid DEFAULT gen_random_uuid() PRIMARY KEY,
    quote_id uuid NOT NULL REFERENCES public.quotes(id) ON DELETE CASCADE,
    share_token text NOT NULL UNIQUE, -- رمز عشوائي طويل لتأمين الرابط
    allow_customization boolean DEFAULT true, -- هل يسمح للزبون بتعديل الكميات؟
    show_alternatives boolean DEFAULT true, -- عرض مقترحات التصميم البديلة
    customer_notes text, -- ملاحظات كتبها الزبون من صفحة الويب
    confirmed_at timestamp with time zone,
    created_at timestamp with time zone DEFAULT now()
);
```

## 📱 واجهة صفحة الويب التفاعلية (Web UI Layout)

تتألف صفحة الويب من المكونات التالية:
* **الهيدر (Header):** لوجو واسم متجر الديكور، وتفاصيل الزبون وتاريخ صلاحية العرض.
* **جدول البنود التفاعلي (Interactive Items Table):**
  * كل صنف (مثال: عود بديل خشب VR-101) يعرض صورته، سعره، الطول، والكمية المقترحة.
  * أزرار (+) و (-) لتعديل الكمية.
  * مؤشر توضيحي لكميات الكرتونة (مثال: إذا عدّل الكمية إلى 15 عوداً، يعرض التطبيق "هذا يساوي كرتونة واحدة تقريباً").
* **قسم الإضافات الاختيارية (Optional Add-ons):**
  * بنود مساعدة (سيليكون تركيب، فوم لاصق، كليبات حديد).
  * مفاتيح تشغيل (Toggle switches) لتفعيل البند أو إلغائه، ليدخل في حساب السعر الإجمالي فوراً.
* **قسم التأكيد والملاحظات:**
  * صندوق لإدخال أي ملاحظات إضافية للمحل (مثل: "أرغب في التوصيل بعد العصر").
  * زر عريض فاخر باللون الأخضر أو الذهبي: **"تأكيد الطلب وإرسال للمحل 🛒"**.
  * بمجرد الضغط، تظهر شاشة نجاح متحركة، ويتم تحويل العميل تلقائياً إلى دردشة WhatsApp للمحل برسالة جاهزة: "لقد قمت بتأكيد عرض السعر رقم #1024 مع بعض التعديلات.. يرجى التحضير".
