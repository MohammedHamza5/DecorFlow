## 🏛️ البنية المعمارية للعزل والاستقلالية (Isolation Architecture)

لتسهيل فصل هذه الميزات مستقبلاً في تطبيق مستقل، نقوم بعزلها برمجياً باتباع المبادئ التالية:

### 1. الكود المصدري (Flutter Code):
* يتم عزل كافة واجهات المستخدم (UI)، منطق العمل (BLoC/Riverpod)، والنماذج (Models) الخاصة بهذه الميزات داخل مجلد `lib/features/premium/`.
* لا يسمح لأي ملف خارج مجلد `premium` باستدعاء أي كود من داخله بشكل مباشر، إلا من خلال مسارات التنقل المحددة في `premium_router.dart` أو واجهة الحقن.
* للتواصل مع بيانات التطبيق الأساسي (مثل معرف المتجر `shop_id` أو جلب قائمة المنتجات)، يتم تعريف واجهة مجردة (Abstract Interface) باسم `PremiumDependencies` تُحقن من التطبيق الأساسي باستخدام Riverpod.

### 2. قاعدة البيانات (Supabase Database):
* جميع الجداول الإضافية تبدأ بالبادئة `premium_` (مثال: `premium_technicians` ، `premium_web_quotes`).
* تحتوي جميع جداول المحفظة ورادار النواقص على حقل `shop_id` لضمان حماية أمن البيانات (RLS Policies) الخاصة بكل متجر.
* عند فصل التطبيق مستقبلاً، يمكن نقل هذه الجداول إلى قاعدة بيانات منفصلة مع تعديل بسيط في عناوين الـ API فقط.
