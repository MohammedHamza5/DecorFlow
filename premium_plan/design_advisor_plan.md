# 🎨 خطة مستشار التصميم الذكي لدمج الخامات (AI Mix & Match Design Advisor Plan)

توضح هذه الخطة البناء الهيكلي لمستشار التصميم وميزة باقات الديكور الجاهزة لحساب مجموعات الخامات المتنوعة التي تغطي جداراً واحداً تلقائياً بضغطة زر.

---

## 💾 هيكل البيانات لقوالب التصميم (Design Templates Database Schema)

سنقوم بإنشاء جداول خاصة بالباقات التصميمية والمنتجات المندرجة تحتها لدعم التخصيص المستقبلي:

```sql
-- 1. جدول الباقات والقوالب الجاهزة
CREATE TABLE IF NOT EXISTS public.premium_design_templates (
    id uuid DEFAULT gen_random_uuid() PRIMARY KEY,
    shop_id uuid REFERENCES public.profiles(id) ON DELETE CASCADE, -- NULL يعني قالب عام افتراضي من النظام
    title_ar text NOT NULL, -- اسم التصميم بالعربية (مثال: حائط كلاسيك رخام وخشب)
    title_en text,
    description_ar text,
    image_url text, -- صورة نموذجية للتصميم ثلاثي الأبعاد أو الواقعي
    is_active boolean DEFAULT true,
    created_at timestamp with time zone DEFAULT now()
);

-- 2. جدول بنود وخامات كل باقة
CREATE TABLE IF NOT EXISTS public.premium_template_materials (
    id uuid DEFAULT gen_random_uuid() PRIMARY KEY,
    template_id uuid NOT NULL REFERENCES public.premium_design_templates(id) ON DELETE CASCADE,
    product_category text NOT NULL, -- قسم المنتج الافتراضي (مثل: بديل خشب، بديل رخام، إكسسوارات)
    calculation_rule text NOT NULL, -- قاعدة الحساب البرمجية (مثلاً: 'panel_center_one_third', 'louver_edges_two_thirds', 'fixed_count')
    unit_multiplier numeric DEFAULT 1.0, -- معامل ضرب الحساب (للاحتياط)
    is_optional boolean DEFAULT false -- هل يمكن للعميل إلغاء هذا الصنف من الفاتورة؟
);
```

## ⚙️ منطق حساب كميات الباقة آلياً (Auto-Calculation Logic)

عندما يختار البائع قالباً معيناً ويدخل أبعاد الحائط المستهدف (العرض $W$ بالسم، الارتفاع $H$ بالسم)، يقوم النظام بتشغيل منطق الحساب المخصص لكل بند:

* **مثال للباقة: "حائط شاشة فاخر (رخام في المنتصف + خشب على الجانبين)"**
  * **اللوح الرخامي في المركز (بديل رخام):**
    * القاعدة: تغطية ثلث عرض الجدار في المركز.
    * الحساب: العرض المستهدف للرخام = $W \times 0.33$.
    * يتم حساب عدد ألواح بديل الرخام المطلوبة لتغطية المساحة: $(\text{العرض المستهدف} \times H) / (\text{عرض اللوح} \times \text{طول اللوح})$.
  * **الأعواد الخشبية على الجوانب (بديل خشب):**
    * القاعدة: تغطية الثلثين المتبقيين على الأطراف بالتساوي.
    * الحساب: العرض المستهدف للخشب = $W \times 0.67$.
    * عدد الأعواد المطلوبة = $\text{العرض المستهدف للخشب} / \text{عرض عود الخشب}$ (مع تقريب الناتج للأعلى لمجابهة قص الفراغات).
  * **شريط الإستانلس الذهبي الفاصل:**
    * القاعدة: 2 خط عمولي بطول الجدار.
    * عدد الأعواد المطلوبة = $(2 \times H) / \text{طول عود الإستانلس}$.
  * **المواد المساعدة (السيليكون):**
    * القاعدة: 1 علبة سيليكون لكل 3 أمتار مربعة من التغطية الإجمالية.

## 📱 واجهات الاستخدام (UI Screens)

1. **معرض القوالب الجاهزة (Design Templates Gallery):**
   * شاشة شبكية (Grid View) تعرض كروت التصاميم مع صور جميلة، وعنوان فريد، ووصف للمواد المستخدمة.
   * خيار لتصفية التصاميم (كلاسيك، مودرن، حوائط شاشات، حوائط غرف نوم).

2. **حاسبة الباقة والتخصيص (Template Calculator & Configurator):**
   * عند الضغط على تصميم، تفتح نافذة الإعداد.
   * يدخل المستخدم عرض الحائط وارتفاعه (بالسنتيمتر).
   * يختار العميل كود الألوان المحدد لكل خامة (يتم جلب الأصناف المتاحة من المخزن تلقائياً بناءً على القسم المحدد في الباقة).
   * يعرض التطبيق فوراً الكميات المحسوبة لكل بند، مع إمكانية تعديل الكمية يدوياً أو تفعيل/إلغاء بعض الإضافات الاختيارية (مثل شريط الليد).
   * زر **"توليد الفاتورة / عرض السعر 📝"** لنقل كافة هذه المواد المحسوبة بأسعارها وصورها مباشرة لسلة المشتريات وعرض السعر بنقرة واحدة.
